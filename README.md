# 写真判定係

ゴールの写真を見て1着を決める、判定係のブラウザゲーム。

**遊ぶ：** https://krieafly8661.github.io/shashin-hantei/

## 遊び方

競技ごとに「どこが決勝線に届いたらゴールか」が決まっています。

| 競技 | ゴールになる部分 |
| --- | --- |
| 陸上 | 胴体（トルソー）。頭・首・腕・脚は数えない |
| 競馬 | 鼻の先 |
| 競輪 | 前輪の先 |
| スケート | 前に出したスケートの刃の先 |

- 写真をなぞると、くらべるための縦の線が動きます。
- 1着のレーンか「同着」を選びます。持ち時間は9秒。
- 連続で正解するほど差は小さくなり、頭や腕、馬の胸など「数えない部分」で先に出ている選手が増えます。6連続からは4レーンになります。
- 3回まちがえたら交代。連続正解数と称号をXに投稿できます。

操作：キーボードなら1〜4でレーン、0で同着、←→で線を動かす（Shiftで細かく）。

## 動かし方

`index.html` を開くだけで遊べます。外部ライブラリは使っていません。

## このゲームを作った理由

2026年10月下旬のXでは『球審ジャッジ』『一塁塁審ジャッジ』『即決裁判』など、審判になって判定するゲームが続けて話題になりました。このゲームは、写真判定という題材に「競技ごとに見る場所がちがう」という実際のルールを組み合わせています。遊ぶと、陸上は胴体、競馬は鼻、という知識がそのまま投稿のネタになります。
